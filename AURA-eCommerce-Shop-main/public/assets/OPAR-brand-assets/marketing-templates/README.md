# OPAR marketing templates

Editable HTML templates and rendered PNG previews using the approved OPAR lockup, oversized emblem backgrounds, and documented brand palette.

## Files

- `01-hero-banner-wide.html` — 2400×1000 website/editorial hero banner.
- `02-social-square.html` — 1080×1080 social feed post.
- `03-social-portrait.html` — 1080×1350 editorial/social portrait.
- `04-social-story.html` — 1080×1920 story/reel cover.
- `05-email-banner.html` — 1600×600 newsletter/email banner.
- `previews/` — rendered PNG previews for quick handoff.

## Editing

Open the HTML in a browser or design handoff environment. Replace the copy inside the `<main>` blocks and update the local image references only if a different approved colorway is required. Keep the logo geometry unchanged. The templates use the OPAR repository palette: Ground `#2F332B`, Main Text `#F4F2EE`, Mist `#D0D3C4`, Button `#9AA66C`, and Accent `#55632A`.

The current copy uses the approved OPAR description and tagline from `data/brand.json`; it is intentionally product-neutral so the templates can be reused for campaigns, journal posts, email, and section announcements.
