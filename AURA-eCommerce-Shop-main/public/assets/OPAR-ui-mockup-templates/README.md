# OPAR UI mockup templates

Standalone editable website UI mockups for the OPAR eCommerce site. This package is separate from `OPAR-brand-assets.zip`. It does not modify the production website.

## Included templates

- `01-homepage-hero-dark.html` — dark homepage hero with oversized orbit background.
- `02-homepage-hero-paper.html` — light/paper homepage hero.
- `03-product-card-grid.html` — three-card shop/category grid.
- `04-featured-product-card.html` — editorial featured-product detail layout.
- `05-newsletter-cta.html` — newsletter/letter sign-up section.
- `previews/` — rendered 1440×900 PNG previews.
- `assets/` — local copies of the approved OPAR logo, mark, background graphics, and existing product photography used by the mockups.

## Design system used

Ground `#2F332B`, Main Text `#F4F2EE`, Mist `#D0D3C4`, Button `#9AA66C`, Accent `#55632A`; serif display tone with a restrained sans-serif interface. The oversized emblem is used as a low-opacity environmental device, never as a replacement for the primary logo.

## How to use

Open any HTML file in a browser. Replace the copy, image references, product names, prices, and links as needed. The layouts are visual mockups, not connected application screens and do not alter production routes or components.
